## Contents

- Top-down/isometric roguelite inspired by Vampire Survivors.
- Auto-attacks and wave survival.
- Selectable characters.
- Implemented abilities per character.
- Experience gems, leveling and upgrade selection.
- Enemy spawning and progressive difficulty.
- HUD for health, experience, level, skills and timer.
- Menus, Game Over, summary screen, sound, music and VFX.

## How to run or install

1. Open the GitHub Releases page linked above.
2. Download the build file available in the **Assets** section.
3. Extract the `.zip` into a local folder.
4. Run the game's `.exe` file.
5. Keep the `.exe` inside the extracted folder, together with the internal files generated by Unity.
